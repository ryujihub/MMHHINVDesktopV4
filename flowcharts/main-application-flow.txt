MMH Hardware Inventory Management System - Complete Application Flowchart

================================================================================
1. ELECTRON APPLICATION STARTUP FLOW
================================================================================

1.1 **Application Launch**
    * User double-clicks MMH Hardware Inventory.exe or runs from command line
    * Electron main process starts (public/electron.js)

1.2 **Single Instance Check**
    * Check if another instance is already running
        * YES: Focus existing window and exit
        * NO: Continue startup

1.3 **Window Creation**
    * Create BrowserWindow with dimensions 1400x900
    * Set web security, node integration, preload script
    * Set icon and window properties

1.4 **Load Application Content**
    * Development Mode:
        * Load from http://localhost:3000 (React dev server)
        * Open DevTools
    * Production Mode:
        * Load from build/index.html (packaged resources)
        * Use fallback paths if needed

1.5 **Window Display**
    * Wait for 'ready-to-show' event
    * Show window and focus
    * Set up error handling and diagnostics

1.6 **Menu Setup**
    * Create application menu with:
        * File: Import Products, Export Report, Exit
        * Edit: Undo, Redo, Cut, Copy, Paste
        * View: Reload, DevTools, Zoom controls
        * Window: Minimize, Close

================================================================================
2. AUTHENTICATION FLOW
================================================================================

2.1 **Initial Load**
    * React app loads (src/index.js)
    * Material-UI theme applied
    * AuthProvider and InventoryProvider initialized

2.2 **Authentication Check**
    * Check if user is authenticated via Firebase Auth
        * NO: Show Login Page
        * YES: Show Main Application Layout

2.3 **Login Page (src/pages/Login.js)**
    * User enters email and password
    * Optional: Create new user account
    * Authentication with Firebase
        * SUCCESS: Redirect to Dashboard
        * FAILURE: Show error message

2.4 **User Creation (Optional)**
    * Open Create User dialog
    * Enter name, email, password, role (staff/admin)
    * Create user in Firebase Auth with custom claims
    * Set permissions based on role

================================================================================
3. MAIN APPLICATION LAYOUT
================================================================================

3.1 **Layout Structure**
    * Sidebar (navigation menu)
    * Header (with menu toggle, notifications)
    * Main content area (routed pages)

3.2 **Navigation Sidebar**
    * Dashboard (overview and stats)
    * Products (inventory management)
    * Categories (product categorization)
    * Sales Orders (order processing)
    * Reports (analytics and reports)
    * Profile (user settings)
    * Settings (system configuration)

================================================================================
4. DASHBOARD PAGE FLOW (src/pages/Dashboard.js)
================================================================================

4.1 **Page Load**
    * Fetch products, categories from InventoryContext
    * Subscribe to recent activity from Firebase
    * Calculate statistics:
        * Total products count
        * Total inventory value
        * Low stock items
        * Product distribution by category

4.2 **Display Components**
    * Statistics cards (Total Products, Total Value, Low Stock)
    * Product distribution bar chart
    * Quick actions (Add Product, View Reports)
    * Low stock alerts list
    * Recent activity feed

4.3 **Admin Setup (if needed)**
    * Check user role and permissions
    * Show admin setup section if user needs admin rights
    * Allow setting current user as admin

4.4 **User Interactions**
    * Click "Add Product" → Navigate to Products page with add dialog
    * Click "View Reports" → Navigate to Reports page
    * Click low stock items → Navigate to Products page

================================================================================
5. PRODUCTS PAGE FLOW (src/pages/Products.js)
================================================================================

5.1 **Page Load**
    * Load products list from Firebase
    * Load categories for filtering
    * Initialize search and filter state

5.2 **Product Management**
    * View products in data grid
    * Search and filter products
    * Sort by various columns

5.3 **Add/Edit Product**
    * Open add/edit dialog
    * Enter product details:
        * Name, description, category
        * Price, cost, stock levels
        * Unit, reorder point
    * Save to Firebase

5.4 **Import/Export**
    * Import from Excel/CSV (via Electron menu)
    * Export product list
    * Bulk operations

================================================================================

6.2 **Order Creation**

6.3 **Order Management**
    * View order history
    * Update order status
